# Queen tech solutions| Landing Page

A fully responsive, production-ready single-file landing page built for Kenyan cyber cafes, business registration bureaus, eCitizen service providers, and website development agencies.

---

## 🌟 Features

- *Accurate Kenyan Service Fee Structure*: Transparent breakdowns of official government charges (BRS/eCitizen statutory fees) bundled together with professional cyber service fees.
- *Direct Omnichannel Communication*: Instant action links connecting clients via Direct Phone Call, WhatsApp, Email, Facebook, Instagram, and LinkedIn.
- *Interactive Live Chat Widget*: Custom-built chat widget featuring automated response logic that guides users through inquiries and lets them transition directly to WhatsApp.
- *Modern Responsive Design*: Engineered with Tailwind CSS for high-speed performance across mobile phones, tablets, and desktop computers.
